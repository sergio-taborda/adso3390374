01-Emmet

Plugin for faster HTML and CSS coding

01-Nesting Elements >

Creates child elements

Example

ul>li>a

Result:

<ul> <li> <a href=""></a> </li> </ul>

02-Sibling Elements +

Creates sibling elements

Example

section+header+nav

Result:

<section></section> <header></header> <nav></nav>

03-Repeat Elements *

Creates multiple elements

Example

ul>li*3

Result:

<ul> <li></li> <li></li> <li></li> </ul>

04-Class Attribute .

Creates elements with a specific class

Example

div.contenedor .contenedor2

Result:

<div class="contenedor"></div> <div class="contenedor2"></div>

05-Multiple Classes ...

Creates elements with multiple classes

Example

div.clase1.clase2.clase3

Result:

<div class="clase1 clase2 clase3"></div>

06-Identifier Attribute #

Creates elements with a specific id

Example

nav#menu

Result:

<nav id="menu"></nav>

07-Add Text {}

Creates elements with text content

Example

div{Lorem Ipsum Dolor} a{Click Aquí}

Result:

<div>Lorem Ipsum Dolor</div> <a href="">Click Aquí</a>

08-Customize Attributes []

Creates elements with custom attributes

Example

a[href=www.google.com]

Result:

<a href="www.google.com"></a>

09-Consecutive Numbers $

Creates elements with consecutive numbers

Example

ul>li.num$*3

Result:

<ul> <li class="num1"></li> <li class="num2"></li> <li class="num3"></li> </ul>

10-Address Consecutive Numbers @-

Creates elements with consecutive numbers

Example

ul>li.num$@-*3

Result:

<ul> <li class="num3"></li> <li class="num2"></li> <li class="num1"></li> </ul>

11-Base Consecutive Numbers @n

Creates elements with consecutive numbers

Example

ul>li.num$@3*4

Result:

<ul> <li class="num3"></li> <li class="num4"></li> <li class=“num5"></li> <li class=“num6"></li> </ul>

12-Level Up ^

Creates elements at a higher level in the hierarchy

Example

section>article>div^p

Result:

<section> <article> <div></div> </article> <p></p> </section>

13-Group Elements ()

Creates elements at a higher level in the hierarchy

Example

(header>nav)(section>article)

Result:

<header> <nav></nav> </header> <section> <article></article> </section>

14-Lorem Lorem

Generates placeholder text.

Example:

lorem

Result:

Lorem ipsum dolor sit amet.

15-HTML DocumentsHtml

Creates various HTML document types.

Example:

html:xs

Result:

<html:xs></html:xs>

16-Meta TagsMeta

Generates meta tags.

Example:

meta:vp

Result:

<meta name="viewport" content="width=device-width, initial-scale=1.0">
